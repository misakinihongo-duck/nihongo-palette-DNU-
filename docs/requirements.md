# Nihongo Palette 要件定義・企画書

## 1. プロジェクト概要

### プロジェクト名
Nihongo Palette

### コンセプト
Nihongo Paletteは日本語教師と生徒がレッスン中に学んだ作文・単語・文法を集め、生徒ごとの復習や読解教材に変換するアプリです。生徒一人ひとりの興味、レベル、学習履歴を色付けするパレットのように、オーダーメイドの日本語学習を支援します。

## 2. 目的と解決したい課題

### 解決したい課題

1. **レッスン進行の悩み**：先生がレッスン中に「次に何をすればよいか」迷うことが多い。
2. **復習準備の負担**：レッスンで学んだ単語や表現をまとめ、復習教材やクイズを作るのに時間がかかる。
3. **英語説明が苦手な先生の支援**：英語が得意でない先生でも外国人学習者をサポートできるようにする。

### 目的
Nihongo Paletteは、上記課題を解消し、先生がレッスンの計画・進行・復習準備に時間を割かずに、生徒に合わせた指導ができる環境を提供します。

## 3. ターゲットユーザー

- オンラインで日本語を教える個人教師
- 日本語を学ぶ外国人学習者

## 4. 基本方針

1. **レッスン中の学びを中心にする**：レッスン内で出てきた作文・単語・文法を記録し、それをそのまま復習や教材作成につなげる。
2. **AIは先生の補助**：AIは先生の説明や教材作成を支援する裏方として利用し、生徒へ直接答えを提示しない。作文添削はAIではなく、先生と生徒が共同で行う。
3. **教員用ビューと生徒用ビューの分離**：同じ画面でも先生にはサポートツールを表示し、生徒には必要な学習情報のみを表示する。

## 5. 主要機能

1. **作文ワークスペース**
   - 生徒が作文を入力し、ふりがなを表示しながら先生と一緒に添削できる。
   - 添削の履歴を保存し、レッスン終了後に確認できる。
   - 作文中の重要な語を単語帳に追加できる。

2. **単語帳・復習クイズ**
   - ワークスペースで追加された語彙を単語帳として管理。
   - 生徒が語彙を使いながらクイズ形式で復習できる。穴埋め問題や実践的な質問も生成する。

3. **JLPTレベル別記事生成**
   - 生徒のJLPTレベルとトピックを入力すると、400字程度の読解記事を生成。
   - 生成した記事と語彙リストを保存し、その語彙を復習クイズに流用する。

4. **講師View専用Teacher Support Panel**
   - **やさしい英語説明**：先生が選んだ単語や表現を簡単な英語で説明。
   - **やさしい日本語説明**：同上をやさしい日本語で説明。
   - **例文生成・質問生成**：単語や文法を使った例文や、生徒に投げかける質問を生成。
   - すべて講師Viewにのみ表示する。

## 6. AI利用方針

- **使用する場面**：Teacher Support Panelの説明生成、例文生成、質問生成、JLPT記事生成、単語クイズ生成。
- **使用しない場面**：作文の自動添削は行わない。添削は学習プロセスとして先生と生徒で協同する。

## 7. 画面要件

1. **ログイン画面**：先生/生徒を選択して仮ログインする。MVPでは認証なしでもよい。
2. **ダッシュボード**：
   - 講師ダッシュボード：担当生徒の一覧、最近の作文や語彙、記事など。
   - 生徒ダッシュボード：自分の作文・語彙・復習クイズ・記事を表示。
3. **作文ワークスペース**：
   - 作文入力エリア、ふりがな表示、添削履歴、単語追加ボタン、Teacher Support Panel（講師Viewのみ）、語彙・復習（生徒View）。
4. **JLPT記事生成画面**：
   - レベルとトピックを入力、生成した記事と語彙を保存。

## 8. MVP範囲

以下を実装対象とする：

- 作文ワークスペース（ふりがな、添削履歴、単語追加）
- Teacher Support Panel（やさしい英語説明・やさしい日本語説明）
- JLPTレベル別記事生成（生成と保存）
- 語彙一覧とクイズ生成（登録語彙に対して簡易的なクイズ出題）

MVPで実装しないもの：

- 本格的な認証/権限管理
- 複雑な学習履歴分析
- 多言語対応
- 音声入力や発音評価など

## 9. 開発フェーズと実装順序

1. **Phase 1: 画面骨格の作成**  
   Next.jsとTailwindでログイン画面・ダッシュボード・作文ワークスペースのUIのみを構築。データはモック。
2. **Phase 2: 作文ワークスペースの機能追加**  
   ふりがな表示、添削履歴保存、単語追加機能を実装。
3. **Phase 3: Teacher Support Panel**  
   選択した語のやさしい英語/日本語説明生成（OpenAI API接続）。
4. **Phase 4: JLPT記事生成**  
   JLPTレベルとトピックを入力して記事と語彙リストを生成・保存。
5. **Phase 5: 単語クイズ生成**  
   保存した語彙を使ったクイズ生成機能を実装。

## 10. 推奨技術構成

- **フロントエンド**：Next.js + TypeScript + Tailwind CSS  
- **公開サーバー**：Render  
- **データベース**：Supabase PostgreSQL  
- **認証**：Supabase Auth（MVPでは仮ログイン可）  
- **ファイル保存**：Supabase Storage（必要に応じて）  
- **AIサービス**：OpenAI API（gpt‑4以降）  
- **デザインツール**：Figma  
- **開発支援**：ChatGPT、Codex（要 AGENTS.md）
