# Nihongo Palette ユーザーフロー

このドキュメントでは、先生と生徒がNihongo Paletteをどのように利用するかのフローをまとめます。

## 先生のフロー

1. **ログイン**: 先生/生徒選択画面で「先生」を選ぶ（MVPでは認証不要）。
2. **ダッシュボード**: 自分が担当する生徒一覧を確認し、対象の生徒を選ぶ。
3. **作文ワークスペース**:
   - 生徒に作文を入力させる。
   - ふりがな表示をオン/オフしながら内容を確認する。
   - 生徒と一緒に誤りを修正し、添削履歴に記録する。
   - 重要な単語を選択して単語帳に追加する。
   - 説明が必要な場合はTeacher Support Panelを開き、やさしい英語/日本語の説明や例文、質問を生成する。
4. **保存**: レッスン終了後、作文、添削履歴、追加した語彙リストを保存する。
5. **記事生成**: 必要に応じて、JLPTレベルとトピックを指定し、生徒のための読解記事を生成して保存する。
6. **クイズ準備**: 保存した語彙リストを基に復習クイズを作成し、次回レッスンや宿題に使う。

## 生徒のフロー

1. **ログイン**: 先生/生徒選択画面で「生徒」を選ぶ。
2. **ダッシュボード**: 自分の作文履歴、語彙リスト、復習クイズ、記事を確認する。
3. **作文**: レッスン中に作文を入力し、先生と一緒にふりがなや修正内容を確認する。
4. **語彙の復習**: 授業後に追加された語彙リストを見直す。
5. **クイズ**: 語彙リストから生成されたクイズに挑戦し、意味や使い方を定着させる。
6. **記事閲覧**: JLPTレベル別に生成された記事を読み、必要に応じて内容理解の質問に取り組む。
